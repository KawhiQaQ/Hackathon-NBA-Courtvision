Hidden Impact · Team 14

让深度数据回到比赛画面：从接应、掩护与防守响应中寻找创造机会的人，再用出手质量解释这次进攻的价值。

如何观看

首页直接播放处理后的视频，无需上传或等待分析。视频内包含有依据的角色标注、跑位方向提示、深度数据卡与分阶段 AI 解说；下方可对照机会质量、引力画像及故事关键帧。有多个已核验回合时，支持回合切换与上传范围内的幕后 MVP 汇总。

数据与解读

  • 视频来源：见各回合的素材来源记录
  • 深度数据：NBA China「深度赛场」。原始出手数据按比赛、球员和事件对应；来源链接随结果提供。
  • AI 解说由 Amazon Bedrock Qwen3-VL 基于视频关键帧、结构化测量及深度数据生成。检测与模型解读可能有误，发布前可复核，复核记录与模型记录分别保留。
  • 预期命中率与同场同球员同类出手均值对照；差值不是某位球员单独造成的命中率提升。阶段汇总 Gravity 用于人物画像，不代表逐帧引力。
  • 画面标注来自视觉检测与短时关联，支持基于原视频校对固定角色和关键位置；箭头提示已观察到的后续移动，不声称重建官方逐帧 tracking。镜头切换和画外位置保留状态，不伪造可见人物。当前独行侠展示采用校对后的角色位置与解说，原始模型任务及复核记录分别保留，展示校对不改写自动评分。
  • 未通过角色证据核验时保留数据解读与成片，不强行授予幕后 MVP。贡献分是工程观察指数，不是已校准的因果价值估计。

实际运行链路

CloudFront 前端 → HTTP API / Lambda 异步队列 → 篮球视觉模型 → Bedrock AgentCore / Qwen3-VL → 候选核验与评分 → 分阶段解说 → FFmpeg/Pillow 视频叠加 → S3 → CloudFront 成片。

全部云端资源在本队 AWS 账号的 us-east-1，通过 CDK 部署。公开作品页只读；上传和分析接口使用团队访问码，密钥不放在网页源码中。

接口与复现

GET /api/health 为公开健康检查。工作台经团队授权后可上传视频和配套数据；POST /api/jobs 创建真实分析任务，GET /api/jobs/{id} 返回状态、解说、证据与可播放结果；POST /api/games 汇总已核验回合；POST /api/presentations 接收绑定原视频哈希的角色与故事校对，在云端重新渲染成片，原始分析结果保持不变。源码仓库提供依赖版本、CDK、准备资产与测试命令，详见仓库 README 和 docs/RESTORE.md。
