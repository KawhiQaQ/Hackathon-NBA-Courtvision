HiAgent

Hidden Impact Agent · 让被忽略的篮球贡献回到画面里。

使用流程

导入单回合视频与可选配套数据，等待分析完成。进入战术影像观看角色标牌、跑位箭头、数据对比和分段解说；切换故事回放查看关键帧证据，再进入数据解读比较机会质量与贡献依据。已有发布结果时，首页直接进入回放。

核心能力

围绕幕后 MVP、受益队友与关键防守者组织分析，解释一次掩护、接应或牵制如何参与机会创造。Reviewer 独立复核角色身份、位置及解说时序，输出统一参考框与呈现计划，并保留原始分析。贡献分是观察指数，不将统计差值直接解释为个人造成的提升。

技术流程

视频与数据 → 篮球视觉检测 → VLM 理解与候选评分 → Reviewer → FFmpeg 视频与故事帧 → 回放和数据展示。本地计算直接调用自己的 Bedrock 模型；在线工作区通过 S3、Lambda、AgentCore 和 CloudFront 承载。

模型证据不足时不强行评选。历史演示与新分析保留各自的生成及复核来源。
