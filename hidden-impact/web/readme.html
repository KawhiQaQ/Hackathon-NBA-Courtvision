Hidden Impact · Team 14

让深度数据回到比赛画面：从接应、掩护、二次进攻与防守响应中寻找创造机会的人，再用出手质量解释这次进攻的价值。

如何观看

首页直接展示成片，无需上传或等待分析。战术回放包含角色标注、方向箭头、战术板与深度数据比较；关键时刻定格，配合分阶段解说。向右切换至故事线与数据分析，也可切回原视频对照。工作台支持导入新素材；多个同场回合支持汇总幕后 MVP 排名。

数据与解读

  • 视频来源：见各回合的素材来源记录
  • 深度数据：NBA China「深度赛场」，按比赛、球员和事件对应出手记录。
  • 解说模块通过 Amazon Bedrock Qwen3-VL 结合关键帧与深度数据生成分段文本，支持发布前编辑。考试素材按官方出手和逐回合记录对齐。当前展示版的角色位置和解说经过人工校对；原始模型分析独立保留。
  • 预期命中率对照同场同球员同类出手均值；差值不等于个人造成的因果增益。阶段引力与此前命中记录用于解释威胁背景。
  • 箭头提示画面中后续移动，战术板呈现相对站位。贡献分是动作证据与机会质量的观察指数，汇总范围为导入的回合集合。

实际运行链路

CloudFront 前端 → HTTP API / Lambda 异步队列 → 篮球视觉模型 → Bedrock AgentCore / Qwen3-VL → 候选核验与评分 → 分阶段解说 → FFmpeg/Pillow 视频叠加 → S3 → CloudFront 成片。

全部云端资源在本队 AWS 账号的 us-east-1，通过 CDK 部署。公开作品页只读；上传和分析接口使用团队访问码，密钥不放在网页源码中。

代码与接口

仓库包含前端、分析与渲染模块、CDK 和测试。GET /api/health 提供健康检查；POST /api/jobs 创建分析任务；GET /api/jobs/{id} 读取结果；POST /api/games 汇总回合；POST /api/presentations 生成编辑后的独立成片。安装及维护说明见仓库 README。
