# Installation and recovery

The current instructions are in the [setup guide](../../docs/setup.md) and [AWS deployment guide](../../docs/aws.md). They use your own credentials and resources; the original event infrastructure is no longer available.

For previously saved private S3 snapshots, see [snapshot-schema.md](snapshot-schema.md). Old annotations and regression fixtures retain their original provenance. They are not automatically loaded into a new deployment.
