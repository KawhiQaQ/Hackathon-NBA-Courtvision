# Example input data

`companion.json` is a clip-aligned input example for the saved Dallas–Houston possession (game `0022500356`, event `273`). `deep-data.json` retains the fuller NBA China data snapshot. These files describe one specific source clip; do not pair them with an unrelated video or feed the annotated replay back in as its original input.

The original `double.mp4` is not stored in Git. For your own video, start with [`../companion.minimal.json`](../companion.minimal.json) and add only facts and timestamps you can verify. All timestamps are seconds relative to the original clip.
