# Annotated replay

`replay.mp4` is the saved HiAgent demonstration (about 40 seconds). `showcase.json` and the five story frames use the same viewer contract as newly generated results. Run `python hidden-impact/scripts/install_demo.py` to view them locally without AWS.

This is a previously calibrated presentation, with reviewed player identities, positions and commentary. It illustrates the rendering capabilities; it is not a benchmark of unassisted model accuracy. The original recording is not included, so original-video comparison is disabled for this bundled preview.

Footage was supplied for the NBA × AWS event; deep data came from [NBA China](https://china.nba.cn/inside-the-game). Basketball footage and third-party data retain their respective owners' rights and are not covered by any license on project code. This archive does not grant redistribution rights.
