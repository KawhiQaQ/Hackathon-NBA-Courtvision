# Team 14 · HI | Hidden Impact

从比赛视频与深度数据中寻找幕后 MVP：识别掩护、接应和防守响应，用角色标注、方向箭头、战术板与分阶段解说呈现机会如何形成。

- [作品说明](https://d2pfr8ulgem4g5.cloudfront.net/readme)
- [功能与接口](hidden-impact/README.md)
- [开发与部署](hidden-impact/docs/RESTORE.md)
- [视觉模型来源](hidden-impact/models/basketball/SOURCES.txt)

作品页默认展示已生成的结果，支持原视频对照、故事线回放与数据分析。工作台支持上传视频及配套数据、创建分析任务、导出结果和汇总同场回合。

所有云资源部署在本队 AWS 账号的 `us-east-1`，由 CDK 管理。凭证、访问码、模型大文件和视频不提交 Git；开发环境准备见部署文档。
